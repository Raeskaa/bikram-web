# 🎯 How to Access the New Events Module

## Quick Start

Your app loads on the **Copilot Showcase** page by default. You'll see a new purple/blue section at the top with 3 buttons to access all the Type B events features!

---

## 📍 Current Location

You're already here! Look for this section at the top of the page:

```
🚀 NEW: Events Module (Type B)

Access the complete standalone events system with 
marketplace, AI promotion, and CRM!

[Events Marketplace] [Create Event] [CRM Dashboard]
```

## 🗺️ Navigation Guide

### 1️⃣ **Events Marketplace** (Purple button)
**What it does**: Browse all public standalone events

**You'll see:**
- Hero section with search bar
- Quick stats (127 events, 12.4K registrations)
- Category filters (Technology, Design, Business, etc.)
- Featured events (large cards)
- Trending events (medium cards)
- All events list

**Try this:**
- Search for events
- Filter by category
- Click any event card → Opens landing page
- Click "Create Event" button → Opens creator wizard

### 2️⃣ **Create Event** (Outline button)
**What it does**: Opens the 5-step event creation wizard

**You'll see:**
- Step 1: Event details (title, description, cover image)
- Step 2: Schedule & format (date, time, virtual/in-person)
- Step 3: **Community funnel** (The Hook! - auto-join community)
- Step 4: Pricing (free vs paid)
- Step 5: **AI Promotion Engine** (multi-channel promotion)

**Try this:**
- Fill in event details
- Click "Generate with AI" to see AI content generation
- Toggle community auto-join
- Enable AI promotion
- Select promotion channels
- Click "Publish & Promote"

### 3️⃣ **CRM Dashboard** (Outline button)
**What it does**: View and manage all event leads/registrations

**You'll see:**
- Stats cards (Total leads, Registered, Attended, No-Show, etc.)
- Search & filter bar
- Table/Card view toggle
- Lead list with:
  - Contact info (name, email, phone)
  - Event registered for
  - Status badges
  - Engagement scores (0-100 with color bars)
  - Source tracking (LinkedIn, Instagram, Email, etc.)
  - Community member status
- Bulk actions (select multiple, send emails, add tags)
- Per-lead actions (view, email, edit, delete)

**Try this:**
- Search for leads
- Filter by status
- Click checkboxes to select multiple
- Click "Bulk Actions" to see options
- Click ⋮ menu on any lead for actions
- Toggle between table and card view

## 🎬 Demo Flow

### Complete User Journey:

**As a Visitor (Attendee):**
1. Click **"Events Marketplace"**
2. Browse events
3. Click **"Backend Development Crash Course"** (first featured event)
4. Landing page opens with full details
5. Click **"Register Now"** (right sidebar)
6. Fill registration form (2 steps):
   - Name, email, company, role
   - Review & confirm
7. **Success!** You're now a member of "Backend Dev Hub" 🎉
8. Click "Go to Community" or "Browse More Events"

**As a Creator:**
1. Click **"Create Event"**
2. Fill Step 1: 
   - Title: "My Amazing Workshop"
   - Click "Generate with AI" to see AI magic ✨
3. Fill Step 2: Pick date, time, virtual/in-person
4. Step 3: Toggle **"Auto-create community"** ✅
   - See "The Hook" explanation
5. Step 4: Choose Free or Paid
6. Step 5: Enable **AI Promotion** ✅
   - Select channels (LinkedIn, Instagram, Email)
   - See predicted reach: "2,500-3,500 people"
7. Click **"Publish & Promote"** → Event goes live! 🚀
8. Navigate to **CRM Dashboard** to see leads coming in

## 🐛 Troubleshooting

**Can't find the Events section?**
- Make sure you're on the main Copilot Showcase page
- Look for the purple/blue box near the top with "🚀 NEW: Events Module (Type B)"

**Modal not closing?**
- Click the X button or "Cancel" button
- If creating an event, click "Save Draft" to close without publishing

**Back button not working?**
- Each view has its own "← Back to Demo" button in the top-left
- Or use the navigation buttons in the purple section
