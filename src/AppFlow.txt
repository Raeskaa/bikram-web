## Auth Flow States (App.tsx)
'signin' → SignIn screen
'register' → Register screen
'forgot-password' → ForgotPassword screen
'all-login-methods' → AllLoginMethods screen
'onboarding' → OnboardingFlow (for new users)
'home' → Main dashboard (after login)

## User States
1. Guest (isGuest = true, guestCredits = 1000)
2. Authenticated (currentUser object, isGuest = false)
3. New User (showOnboarding = true)
4. Returning User (resume where left off)
